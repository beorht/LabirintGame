Как играть
Напишите команды для управления героем. Дойдите до финиша 🚩 и вызовите hero.finish(). Программа всегда запускается со старта. Впереди 14 уровней — пройдите их по порядку.
Команды
hero.down() // шаг вниз hero.up() // шаг вверх hero.left() // шаг влево hero.right() // шаг вправо hero.finish() // закончить уровень
Циклы — с уровня 5
repeat(3) { hero.right(); } // три шага вправо
