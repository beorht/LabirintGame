## 🛠️ Стек технологий

### MVP (сейчас)
```
Frontend:     Vanilla JS + HTML5 Canvas
Backend:      Node.js + Express
Database:     JSON files (переход на PostgreSQL)
Hosting:      Localhost
Auth:         Простая (localStorage)
```

### Масштабирование (PHASE 2-3)
```
Frontend:     React.js + Canvas.js
Backend:      Node.js + Express + Redis
Database:     PostgreSQL
Hosting:      Vercel + DigitalOcean
Auth:         JWT + OAuth2 (Google, GitHub)
Analytics:    Plausible.io
```

### Полная платформа (PHASE 4-5)
```
Frontend:     React.js + Tailwind CSS
Mobile:       React Native
Backend:      Node.js + GraphQL
Database:     PostgreSQL + MongoDB
Cache:        Redis
Search:       Elasticsearch
Hosting:      AWS/GCP
CDN:          Cloudflare
```
