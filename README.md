# 🎮 Maze Quest

Образовательная браузерная игра: персонажа по лабиринту ведут команды, которые игрок пишет в редакторе кода. Игра учит алгоритмическому мышлению и поиску пути.

```javascript
hero.right();
hero.right();
hero.down();
hero.finish();
```

## Требования

- **Node.js 18+** (проверено на v26) и npm
- Современный браузер (Chrome, Firefox, Safari, Edge)

Сама игра работает в браузере без сборки. Node.js нужен для сервера (сохранение карт, результаты, админ-панель) и для тестов.

## Установка

```bash
git clone <url-репозитория> LabirintGame
cd LabirintGame
npm install
```

## Запуск

### Вариант 1. Полный (с сервером)

```bash
ADMIN_PASSWORD=ваш_пароль npm start
```

- Игра: **http://localhost:3000/index.html**
- Админ-панель: **http://localhost:3000/admin** (логин `admin`, пароль из `ADMIN_PASSWORD`)

Порт по умолчанию — `3000`, его можно сменить: `PORT=4000 ADMIN_PASSWORD=... npm start`.

Если `ADMIN_PASSWORD` не задан, игра работает, но админ-панель отключена (`/admin` вернёт 503).

### Вариант 2. Только статика (без сервера)

Достаточно любого статического HTTP-сервера в корне проекта:

```bash
python3 -m http.server 8000
# или
npx http-server -p 8000
```

Открыть: **http://localhost:8000/index.html**

В этом режиме кампания работает полностью, но сохранение карт, отправка результатов и админ-панель недоступны.

## Тесты

```bash
npm test
```

Запускает `node --test` по `tests/*.test.js`: генераторы и решатели, парсер команд, настройки и эталонные решения всех 14 уровней.

## Как играть

1. Введите имя игрока. Прогресс сохраняется в браузере под этим именем.
2. Напишите команды в редакторе справа.
3. Нажмите **▶ Выполнить** (или `Ctrl+Enter`). Персонаж пройдёт команды по одной с анимацией.
4. Дойдите до финиша 🚩 и вызовите `hero.finish()`.

### Команды

| Команда | Действие |
|---------|----------|
| `hero.up()` | Шаг вверх |
| `hero.down()` | Шаг вниз |
| `hero.left()` | Шаг влево |
| `hero.right()` | Шаг вправо |
| `hero.finish()` | Завершить уровень (на клетке финиша) |
| `repeat(N) { … }` | Повторить блок N раз (1–20), с 5-го уровня |

Синтаксис: одна команда на строке, `//` — комментарий. Вложенные `repeat` открываются с 10-го уровня.

### Элементы карты

| Элемент | Обозначение | Эффект |
|---------|-------------|--------|
| Стена | ■ | Проход запрещён (попытка вызывает ошибку) |
| Путь | □ | Проходимая клетка |
| Старт | A | Начальная позиция |
| Финиш | 🚩 | Цель |
| Ловушка | ✕ | +5 шагов, срабатывает один раз |
| Монета | ★ | Собирается, считается в HUD |

### Кнопки

- **▶ Выполнить** — запустить код
- **↻ Сброс** — вернуть героя на старт (код остаётся)
- **💡 Подсказка** — дописать до 5 команд, продолжающих текущий код
- **🤖 Демо** — автоматическое решение выбранным алгоритмом
- **⚙️ Настройки** — пауза между командами
- **🎨 Персонаж** — загрузить свой PNG персонажа
- **👤 Игрок** — сменить игрока

Звёзды (⭐⭐⭐) зависят от числа шагов относительно оптимального пути. На уровнях 5+ превышение лимита строк кода снижает оценку до ⭐⭐.

## Админ-панель

Страница **`/admin`** показывает игроков и их результаты по кампании:

- сводка: число игроков, прохождений уровней, кампаний пройдено;
- таблица игроков: уровней пройдено, суммарные лучшие шаги, монеты, время, звёзды, число попыток;
- по клику на игрока — результаты по каждому уровню: шаги относительно оптимума, монеты, время, звёзды.

Для каждого уровня берётся лучшая попытка: сначала больше звёзд, затем меньше шагов.

Защита — HTTP Basic: логин `admin`, пароль из переменной окружения `ADMIN_PASSWORD`. Пароль нигде не хранится в коде.

> Результаты отправляются с клиента без аутентификации игрока, поэтому их можно подделать. Панель подходит для учебного использования, но не для честного рейтинга.

## API

Все маршруты сервера:

| Метод | Путь | Доступ | Описание |
|-------|------|--------|----------|
| `GET` | `/api/maps` | все | Список пользовательских карт, новые первыми |
| `GET` | `/api/maps/:id` | все | Полные данные карты |
| `POST` | `/api/maps` | все | Сохранить карту (`name`, `maze`, координаты, `traps`, `coins`) |
| `DELETE` | `/api/maps/:id` | все | Удалить карту |
| `POST` | `/api/results` | все | Записать победу на уровне кампании (`player`, `level`, `stars`, `steps`, `optimalSteps`, `coins`, `totalCoins`, `timeSec`) |
| `GET` | `/api/admin/results` | admin | Все результаты, новые первыми |
| `GET` | `/admin` | admin | Админ-панель |

Карта — квадрат от 5×5 до 25×25 из `0` (путь) и `1` (стена).

Пример:

```bash
curl http://localhost:3000/api/maps
curl -u admin:ваш_пароль http://localhost:3000/api/admin/results
```

## Хранилище в браузере

В `localStorage` сохраняется:

- `theme` — светлая/тёмная тема
- `settings` — настройки скорости
- `mazeQuestPlayers` — прогресс игроков
- `mazeQuestPlayer` — последний игрок
- `customCharacter` — PNG персонажа
- `customLevel` — последняя карта из конструктора

Чтобы сбросить всё, очистите данные сайта для `localhost` в настройках браузера.

## Конструктор уровней

Логика конструктора (`scripts/editor.js`) и API карт сохранены, но кнопка **🔧 Редактор** убрана из интерфейса, поэтому открыть конструктор из игры сейчас нельзя. Чтобы вернуть его, добавьте кнопку с `id="editorButton"` в шапку `index.html`.

## Решение проблем

- **Порт 3000 занят.** Остановите процесс, который его занимает, либо задайте другой `PORT`.
- **Карты или результаты не сохраняются.** Проверьте, что запущен `npm start`, а не `http.server`: без сервера API недоступен.
- **`/admin` требует пароль, но не принимает его.** Проверьте, что сервер запущен с тем же `ADMIN_PASSWORD`, что вы вводите.
- **Панель показывает «Админ-панель отключена».** Сервер запущен без `ADMIN_PASSWORD`.
- **`npm test` падает после правок уровней.** Проверьте эталонное решение в `tests/levels.test.js`: оно должно совпадать с картой и `maxLines`.
